INSTALLATION

How to install

  1. Open MetaTrader 5.
  2. Choose File → Open Data Folder.
  3. Open MQL5 → Experts.
  4. Copy BULLHUNTERINSIGHT-100L-0.10.ex5 into the folder.
  5. Restart MT5 or refresh Navigator.
  6. Open the correct XAUUSD chart and attach the EA.
  7. Review every input before enabling automated trading.
  8. Demo-test before considering live funds.
