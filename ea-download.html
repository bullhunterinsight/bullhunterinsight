INSTALLATION

How to install an EA

  1. Open MetaTrader 5.
  2. Open File → Open Data Folder.
  3. Open MQL5 → Experts.
  4. Copy the EA file into the Experts folder.
  5. Restart MetaTrader 5 or refresh Navigator.
  6. Open the EA on the correct chart and review every input.
  7. Enable AutoTrading only after you understand the configuration.
  8. Demo-test before considering live deployment.
